Sistem Informasi Perpustakaan

Program perpustakaan berbasis Java yang menampilkan menu untuk melihat informasi buku, meminjam buku, mengembalikan buku, dan keluar dari program. Contoh ini menggunakan konsep class dan object untuk mengelola informasi buku serta stoknya.
